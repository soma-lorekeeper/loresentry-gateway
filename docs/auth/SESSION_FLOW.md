# BFF 세션 활동과 만료

2026-09-26 목표 계약이다. 일반 보호 요청이 인증에 성공하면 마지막 활동으로부터
14일로 만료를 연장한다. 별도의 브라우저 연장 요청은 필요하지 않다.

1. 변경 요청의 CSRF를 먼저 검사한다.
2. 단일 쿠키의 ID 형식을 검증하고 SHA-256으로 해시한다.
3. 공유 저장소의 ID 인덱스를 조회한 뒤, 현재 사용자 세션과의 일치 확인·TTL 연장을
   한 스크립트로 수행한다. 사전 조회만으로 사용자를 인증하지 않는다.
4. 성공한 사용자 UUID만 내부로 전달한다. 응답에는 같은 ID의 쿠키 만료를 갱신한다.

[공유 세션 계약](../../../loresentry-authentication/docs/session/SESSION_DESIGN.md#보호-요청의-검증과-연장)의
두 키·재검증·500ms 전체 예산을 따른다. 부재·만료는 재로그인, 장애·손상·결과 불명은
일시 오류로 처리하며 쿠키를 변경하지 않는다. 오류별 응답은 [외부 API](../EXTERNAL_API.md)를 따른다.

동시 활동은 같은 ID를 유지한다. 로그아웃·새 로그인 이후 이전 요청으로 세션을 생성하거나
연장할 수 없어야 한다. 이미 검증을 통과한 요청은 소급 취소하지 않는다.
브라우저 응답 순서의 한계와 인증 전환 조율은 [프론트 인계](../FRONTEND_AUTH_CONTRACT.md)를 따른다.
