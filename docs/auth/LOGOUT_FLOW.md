# BFF 로그아웃 연동

2026-09-26 목표 계약이다. 외부 경로는 `POST /auth/sessions/revoke`다.

1. CSRF를 검사한다. 실패하면 내부 호출·쿠키 변경 없이 거절한다.
2. 단일 세션 쿠키가 없으면 Auth 호출을 생략한다. 중복·형식 오류는 입력 거절로 처리한다.
3. 정상 ID는 Auth의 같은 경로에 `session_id` 본문으로 전달해 조건부 폐기를 요청한다.
4. 폐기 성공·실패와 별개로 같은 범위의 세션 쿠키 삭제 헤더를 반환한다.
5. [외부 API](../EXTERNAL_API.md#로그아웃-응답)의 session_revocation으로 폐기 확인 여부를 전달한다.

Auth는 입력 세션만 폐기한다. 이전 로그인 ID로 새 로그인을 지울 수 없다.
부재·만료·이미 교체된 ID는 사용 불가 상태로 완료한다. 상세 원자성과 제한적 폐기 재시도는
[세션 계약](../../../loresentry-authentication/docs/session/SESSION_DESIGN.md#로그아웃)을 따른다.
BFF는 내부 HTTP를 자동 재시도하거나 백그라운드 폐기를 추가하지 않는다.

삭제 헤더만으로 서버 폐기나 브라우저 적용을 보증하지 않는다. 새 로그인과 늦은 삭제 응답이
겹치지 않도록 [프론트 인증 전환](../FRONTEND_AUTH_CONTRACT.md)을 조율하고 실제 브라우저로 검증한다.
