# LOREKEEPER-589 인증 전환 잔재 제거

2026-09-26, 기존 토큰 필터·검증·재발급·폐기 경로와 DTO, 키 로딩·설정 및
서비스 JWT 라이브러리를 제거했다. 보호 요청은 단일 세션 필터만 사용한다.
JWT 키 없는 애플리케이션 기동, OAuth·계정·Content 회귀, build와 Redis/Valkey
세션 통합 테스트를 통과했다. 이전 쿠키와 Bearer 입력만으로는 인증되지 않는다.

이전 쿠키의 일회성 정리는 AuthCookies.clearLegacy가 담당한다. 로그인 성공 또는
CSRF를 통과한 로그아웃에서 요청에 존재하는 현재 환경의 이전 쿠키만 삭제한다.
Path=/·Domain 없음·환경별 Secure를 유지하며 새 세션 쿠키 이름은 포함하지 않는다.
단위 및 HTTP 테스트로 삭제 범위와 인증 실패 시 쿠키 보존을 확인했다.

과거 검증 기록은 그대로 보존하며 실행 도구·안내는 Atomic 590에서 갱신한다.
