# 최종 BFF 문서 정합화

2026-09-24, LOREKEEPER-577. README·설계·브라우저 보안·Auth 흐름·Content 계약을
현재 코드와 검증 결과에 맞췄다. 임시 사용자 헤더 인증·namespace relay·원문 오류 전달과
저장소 미조회 설명을 현재 AT·단일 세션·명시적 DTO 계약으로 교체했다.

`.env.local.example`에 local 프로필의 필수 설정을 제공하고 실제 환경 파일·키 디렉터리를
Git·Docker context에서 제외했다. [운영 준비](../OPERATIONS.md)와 [공동 전환](../ROLLOUT.md)은
설정·ACL·접근 제한, sid 없는 토큰 재로그인, 혼재 방지·진행 요청 배출·TTL 정리·fallback
금지·구버전 롤백의 세션 부활 위험을 명시한다. 프론트 인계에는 credentials·CSRF·result
확인·next_action·탭 조율·Content 저장 헤더를 연결했다.

코드의 경로·응답·쿠키·CORS·필수 환경 변수, 실제 검증 기록과 문서를 대조했다. 변경 문서의
상대 경로 존재 여부, 설정 예시의 필수 변수, 환경 파일 ignore 규칙과 `git diff --check`를
확인했다. 새 동작을 추가하지 않은 문서·예시 변경이므로 단위 테스트를 새로 만들지 않았다.
Work 통합 후 기존 전체 build·세션 통합 태스크를 다시 확인한다.

과거 이슈별 검증 수치와 조사 당시 사실은 보존하고 최신 결과를 별도로 연결했다.
프론트 의존 검증의 사용자 승인 제외는 실제 브라우저 검증 성공을 뜻하지 않는다.
운영 준비도 미완료이며, 운영 배포·외부 프론트·인프라 변경은 수행하지 않았다.
